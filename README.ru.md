**Parsec Clipboard Isolator** — это лёгкая утилита для Windows, предназначенная для изоляции и программного контроля буфера обмена при работе с [Parsec](https://parsec.app/).

---

## 🎯 Проблема и Идея

В Parsec буфер обмена по умолчанию синхронизируется между вашим основным устройством и удаленными сессиями. Из-за этого возникает частая проблема:
* Скопированный текст на удаленной машине перезаписывает ваш локальный буфер обмена на основном ПК.
* Личные данные, конфиденциальная информация или пароли могут случайно попасть в чужую сессию.

Единственное эффективное и удобное решение — **программно изолировать глобальный буфер обмена Parsec**, сохранив при этом полную свободу работы внутри каждого окна.

---

## 🔒 Как работает изоляция

1. **Запуск на Main-устройстве**: Утилита запускается на вашем основном ПК (клиенте) и контролирует глобальное состояние передачи буфера обмена Parsec.
2. **Личный буфер остаётся личным**: Скопированные данные на вашем основном ПК защищены и никогда не будут автоматически перезаписаны удаленной сессией.
3. **Локальная работа внутри Parsec**:
   * Находясь в окне подключенного ПК, вы можете свободно использовать `Ctrl+C` и `Ctrl+V`.
   * Текст копируется и вставляется **внутри той удаленной системы**.
   * При этом скопированный текст **не попадает** в буфер вашего основного устройства и **не перезаписывает** его.
4. **Безопасность удаленных систем**: Каждое подключенное устройство сохраняет свой собственный независимый буфер обмена. Утилита никак не нарушает работу ОС на удаленных машинах.
5. **Гибкое управление**: Вы можете включить или выключить синхронизацию буфера обмена в любой момент по желанию.

## ✨ Ключевые возможности

* 🪟 **Поддержка нескольких окон**: Автоматически отслеживает и изолирует все активные окна Parsec.
* 🛡️ **Безопасность**: Работает на уровне стандартных Windows API (без внедрения DLL, драйверов или опасного перехвата).
* ⚡ **Легковесность**: Нулевая нагрузка на процессор (0% CPU) и минимальное потребление оперативной памяти.
* 🎛️ **Управление в один клик**: Быстрый переключатель режимов изоляции.

## 🚀 Запуск и Сборка

### Требования
* ОС: Windows 10 / 11
* [.NET 9.0 Runtime](https://dotnet.microsoft.com/download) (или новее)

### Сборка из исходников

```bash
git clone https://github.com/InfernalVoooid/ParsecClipboardIsolator.git
cd ParsecClipboardIsolator
dotnet build -c Release
```
